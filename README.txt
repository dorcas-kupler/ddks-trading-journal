DDK'S TRADING JOURNAL — PRIVATE PC APP

1. Keep these files together in the same folder.
2. Double-click "Open DDK Trading Journal.bat".
3. To create a desktop icon: right-click the .bat -> Show more options -> Send to -> Desktop (create shortcut).
4. The journal works offline and stores its data locally in the browser profile used to open it.

IMPORTANT
- Do not delete or clear the browser's site data/profile if you want to keep your saved journal data.
- This standalone version no longer depends on the original Claude artifact runtime.
- No domain is required.
