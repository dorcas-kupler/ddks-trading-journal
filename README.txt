DDK'S TRADING JOURNAL — PWA EDITION

This folder is a Progressive Web App (PWA).

To make it installable for you and your friends, publish this folder on an HTTPS web host.
Do not open index.html directly from a file:// URL if you want the Install App feature.

Once hosted:
1. Share the web link.
2. On PC/Chrome/Edge: open the link and use the Install button or the browser's Install App option.
3. On Android: open the link in Chrome and use Install app / Add to Home screen.
4. On iPhone/iPad: open in Safari, tap Share, then Add to Home Screen.

The service worker caches the app so it can continue working offline after the first successful visit.

IMPORTANT: The journal currently uses browser local storage. Each person's device/browser keeps its own data; this PWA does not automatically create a shared cloud database.
